2.worker.js 수신 & 코드 리뷰

3개 라우팅 블록 확인: /kis/* → KIS API, /dart/* → DART API, ?url= → Yahoo/Finviz/CNN 원본 유지

// ── /kis/ 처리 — 정상 ──
const kisPath = url.pathname.slice(4);
// "/kis/oauth2/token" → slice(4) → "/oauth2/token"  ✓

// ── /dart/ 처리 — 버그 ──
const dartPath = url.pathname.slice(6);   ← BUG
// "/dart/api/list.json"
//  [0123456]
// slice(6) → "api/list.json"  ← '/' 없음
// → https://opendart.fss.or.krapi/list.json  ← URL 깨짐

원인: /dart는 5글자. slice(5)로 해야 이후 /api/...가 그대로 붙음.

FIX

3.worker.js 버그 수정

// 수정 전
const dartPath = url.pathname.slice(6);

// 수정 후
const dartPath = url.pathname.slice(5);
// "/dart/api/list.json" → slice(5) → "/api/list.json"  ✓
// → https://opendart.fss.or.kr/api/list.json  ✓
