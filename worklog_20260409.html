1. RECONKR — DART API 통합

배경

  • 기존 DART는 외부 링크 버튼만 있었고 API 연동 없음
  • DART 공시를 Claude 분석 프롬프트에 자동 포함시키는 게 목표

HTML 변경

  • 설정 화면에 DART API 섹션 추가 (Claude API, KIS API 사이에 삽입)
  • 대시보드 DART 외부링크 버튼 → DART 공시피드 버튼으로 교체 (최근 3일 주요사항 인라인 표시)
  • MOMO / SWING 스크리너 하단에 공시 필터 토글 추가 (전체 → 공시있음 → 공시없음)

JS 추가 함수

  • fetchDart(apiPath, params) — Oracle 서버 경유 DART API 호출 헬퍼
  • saveDart() / updateDartStatus() — 키 저장 및 상태 표시
  • testDartConnection() — 연결 테스트
  • fetchDartCorpCode(stockCode) — 종목코드 → DART corp_code 변환 (캐시 포함)
  • fetchDartDisclosures(stockCode) — 최근 30일 공시 목록 조회
  • classifyDartDisclosures(list) — 팩트/부정/일반 분류
  • loadDartFeed() — 대시보드 공시 피드 로딩
  • toggleDartFilter(mode) — 스크리너 공시 필터

분석 파이프라인 수정

  • Yahoo 뉴스 fetch 직후 DART 공시 자동 조회 (step 3-b 추가)
  • [DART공시] + [뉴스] 합쳐서 newsText 구성
  • 부정공시 감지 시 newsQualityHint = 'negative' 강제 처리
  • Claude 프롬프트에 === DART 전자공시 (최근 30일) === 섹션 추가

2. DART 프록시 서버 구축 — 시도 이력

시도방법결과실패 원인
1Cloudflare Worker ?url= generic proxy❌ 실패허용 목록에 opendart.fss.or.kr 없음 → 403
2Cloudflare Worker /dart/ 엔드포인트❌ 실패DART 서버가 Cloudflare IP 대역(172.69.x.x) 전체 차단
3Cloudflare Tunnel (trycloudflare.com)❌ 실패trycloudflare.com 자체가 Cloudflare 망 → 동일 차단
4Oracle 서버 직접 http://140.245.78.29:3000❌ 실패GitHub Pages(https)에서 http mixed content 차단
5 ✅Oracle 서버 + HTTPS https://dart.minon.kr✅ 성공—

Cloudflare Worker 버그 (참고)

  • url.pathname.slice(6) → slice(5) 수정 필요 (슬래시 보존 문제)
  • User-Agent 없으면 DART 서버 502 반환 → headers 추가 필요
  • 결국 Cloudflare IP 차단으로 Worker로는 해결 불가

Node.js 설치

# apt 기본 버전(12.x)은 너무 낮아서 nodesource 사용
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -

# 충돌 발생 → 구버전 완전 제거 후 재설치
sudo apt-get remove -y nodejs libnode-dev libnode72
sudo apt-get autoremove -y
sudo apt-get install -y nodejs
# 최종: v20.20.2

Express 시도 실패 이유

  • Express 5 버전이 설치됨
  • app.get('/dart/*') → path-to-regexp 문법 변경으로 에러
  • app.get('/dart/:path(*)') → 동일 에러
  • 결론: Express 버리고 Node 내장 http/https 모듈로 전환

dart-proxy server.js (최종)

const https = require('https');
const http  = require('http');
const fs    = require('fs');

const options = {
  key:  fs.readFileSync('/etc/letsencrypt/live/dart.minon.kr/privkey.pem'),
  cert: fs.readFileSync('/etc/letsencrypt/live/dart.minon.kr/fullchain.pem'),
};

// HTTPS 443 + HTTP 80 → 301 리다이렉트
https.createServer(options, handler).listen(443);
http.createServer((req, res) => {
  res.writeHead(301, { Location: 'https://dart.minon.kr' + req.url });
  res.end();
}).listen(80);
  • /dart/* 요청 → https://opendart.fss.or.kr 프록시
  • User-Agent, Referer 헤더 포함

DNS 설정 (가비아)

  • 도메인: minon.kr
  • A 레코드: dart.minon.kr → 140.245.78.29 (TTL 600)
  • ⚠️ TTL 최솟값이 600이어서 600으로 설정

Oracle Security List (방화벽)

  • 포트 80, 443, 3000 Ingress Rule 추가
  • Source: 0.0.0.0/0, Protocol: TCP
  • ⚠️ Source Port Range가 아닌 Destination Port Range에 입력해야 함

Oracle 내부 iptables

sudo iptables -I INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT -p tcp --dport 443 -j ACCEPT
sudo iptables -I INPUT -p tcp --dport 3000 -j ACCEPT

⚠️ 재부팅 시 초기화됨 — pm2 startup으로 서버 자동 재시작은 해결되지만 iptables는 별도로 영구 저장 필요 (iptables-persistent)

Let's Encrypt 인증서

sudo certbot certonly --standalone -d dart.minon.kr \
  --email contact@minon.kr --agree-tos --non-interactive

# 만료: 2026-07-08 (자동 갱신 설정됨)

⚠️ 발급 전 포트 80을 Oracle Security List + iptables 양쪽 다 열어야 함

pm2 영구 실행 설정

sudo npm install -g pm2
sudo pm2 start ~/dart-proxy/server.js --name dart-proxy
sudo pm2 startup
sudo pm2 save
# 이후 서버 재부팅, 터미널 종료해도 자동 실행

4. RECON (미국주식) — Yahoo v6 → v8 교체

문제

Yahoo Finance v6/finance/quote 엔드포인트 404 반환
에러: Unexpected token '<', "<!DOCTYPE "... is not valid JSON

원인

Yahoo가 v6 API 비공개 처리 (HTML 에러 페이지 반환)

수정

  • loadMarketData() — SPY/QQQ/VIX를 v8 chart로 각각 fetch
  • fetchYahooData() — v6 quote → v8 chart meta에서 데이터 추출
  • avgVolume = 최근 5일 거래량 평균으로 대체
  • float, short%, bid/ask, marketCap은 v8에 없어서 null 처리
